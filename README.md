# 🚀 DSA Fundamentals in C#

![C#](https://img.shields.io/badge/C%23-239120?style=for-the-badge&logo=c-sharp&logoColor=white)
![.NET Framework](https://img.shields.io/badge/.NET_Framework-512BD4?style=for-the-badge&logo=dotnet&logoColor=white)

A comprehensive repository for learning and practicing core Data Structures and Algorithms. This project is built as a **C# .NET Framework Console Application**. The learning path follows a strict hierarchical tree, starting from fundamental arrays and branching out to advanced algorithmic techniques.

## 📁 Project Structure

The repository folders are organized to reflect the hierarchical roadmap:

```text
DSA_Fundamentals/
│
├── 1_Arrays/
│   ├── StackAndQueue/
│   ├── Hashing/
│   ├── PrefixSum/
│   └── TwoPointers/
│       └── SlidingWindow/
│
├── 2_SortingAndSearching/
│   ├── Sorting/
│   └── BinarySearch/
│
├── 3_LinkedStructures/
│   └── LinkedList/
│
├── 4_TreesAndHeaps/
│   ├── Tree/
│   └── Heap/
│
├── 5_RecursionAndAdvancedAlgorithms/
│   ├── Recursion/
│   ├── Backtracking/
│   ├── DynamicProgramming/
│   └── Graph/
│
└── Program.cs
```
